Karaoke Catalog Builder

Reads every video from your chosen channels and builds one catalog file per language (Malay, English, Korean, Indonesian, Others). The app searches those files, so visitors use no YouTube quota.
1. YouTube API key
2. Channel list Choose the channels.json you downloaded from the Finder.
Add a channel
Open the channel on YouTube, copy the address from the top, and paste it here. Links that look like youtube.com/@name or youtube.com/channel/UC... both work.
3. Build
Reading a channel costs about 1 unit per 50 videos, so this stays far below your 10,000 daily units. It can take a few minutes. Keep this page open.
